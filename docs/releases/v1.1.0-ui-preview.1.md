# YOLO 视觉 v1.1.0-ui-preview.1

本次预览版统一首页、实时检测和视频采集页面的视觉设计。

- 深色 Material 主题、薄荷绿强调色、卡片式采集入口。
- 按宽度适配的 4:3 相机预览，分组展示模型、推理设备与位置信息。
- 中文按钮、返回入口、无障碍标签与更大的点击区域。
- 录制状态由 CameraX 回调更新；保存期间禁用开始录制与切换镜头。

## 下载

`Yolo11Android-v1.1.0-ui-preview.1-debug.apk` 为 Debug 测试包，包含 arm64-v8a、armeabi-v7a、x86、x86_64；支持 Android 7.0 / API 24 及以上。APK 内版本为 1.1（versionCode 1）。

`ui-preview.png` 为依据界面 XML 制作的静态效果预览，非实机截图；相机与地图为占位。

![静态效果预览，非实机截图](https://github.com/Mrchips233/Yolo11Android-/releases/download/v1.1.0-ui-preview.1/ui-preview.png)
